 MiniPay – Implementation & L2 Support Engineer Assessment

MiniPay is a small payment-processing application (web UI + REST API + PostgreSQL)
built for the Paysys Labs technical assessment. This repo covers deployment,
operations, database/SQL investigation, Python support tooling, API/UI test
automation, and three incident investigations.

See ARCHITECTURE.md for design, SETUP.md to reproduce the environment,
and AI_USAGE.md for how AI tools were used in building this.
